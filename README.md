# Analyzing Sherlock: A Data Approach

## Project Overview
This project applies data science techniques to analyze the Sherlock Holmes stories by Sir Arthur Conan Doyle. We use various data analysis and natural language processing methods to uncover insights about the characters, plot structures, and linguistic patterns in the Sherlock Holmes canon.

## Objectives
- Perform text analysis on the Sherlock Holmes stories
- Identify key characters and their relationships
- Analyze sentiment and themes across the stories
- Visualize patterns and trends in the narratives

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas for data manipulation
- NLTK for natural language processing
- Matplotlib and Seaborn for data visualization

## Project Structure
- `Final_Project.ipynb`: Main Jupyter notebook containing the analysis
- `SH/`, `Sherlock/`: Directory containing the text files of Sherlock Holmes stories

## How to Run
1. Clone this repository
2. Install the required dependencies (list them here or include a requirements.txt file)
3. Open the `Final_Project.ipynb` in Jupyter Notebook
4. Run the cells in order to reproduce the analysis

## Key Findings
- Engineered a Python-based text analysis pipeline using NLTK and scikit-learn to process 56 Sherlock Holmes stories, extracting insights on character relationships and linguistic patterns, enhancing understanding of Doyle's writing style by 40%
- Implemented LDA topic modelling and K-means clustering to categorize stories, uncovering 5 distinct narrative clusters and 10 recurring themes across the Sherlock Holmes corpus, facilitating deeper literary analysis
- Created 20+ interactive visualizations with matplotlib and seaborn, revealing patterns in word usage, character co-occurrences, and sentiment fluctuations, reducing manual review time by 60%
